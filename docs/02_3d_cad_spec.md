# 02 · 3D 硬件尺寸规格、配合公差与打印指南

本模块对应目录：`3d_hardware/`，所有文件均采用**真实毫米（mm）制**，并通过 `trimesh + manifold3d` 生成为 **100% 闭合水密流形（`watertight=True`）**。

---

## 一、 核心设计：盖子 + 倒圆锥高台支架（主推组合）

### 1. 鸟类盖子规格（`caps_embossed/` 凸起版 & `caps_engraved/` 凹刻版）
| 参数项 | 凸起浮雕版 | 凹刻挖槽版 | 说明 |
| :--- | :--- | :--- | :--- |
| **外圆直径** | `Ø 31.0 mm` | `Ø 31.0 mm` | 外壁厚 `2.3 mm`，上下边缘均带倒角 |
| **顶部边缘倒角** | `0.4 mm × 45°` | `0.4 mm × 45°` | 改善手持边缘质感 |
| **背面 NFC 挖槽直径** | `Ø 26.4 mm` | `Ø 26.4 mm` | 为 `26 mm` 圆形芯片预留 `+0.4 mm` 热收缩公差 |
| **背面槽入口导角** | `Ø 26.9 mm (深0.25mm)` | `Ø 26.9 mm (深0.25mm)` | 消除底部首层“象脚效应”，便于芯片与支架卡入 |
| **背面挖槽深度** | `1.3 mm` | `1.3 mm` | 顶部先贴极薄 NFC 贴纸（约0.2mm），余下空间卡入支架 |
| **正反面隔离壁厚** | `1.2 mm` (`Z=1.3~2.5`) | `1.1 mm` (`Z=1.3~2.4`) | 彻底隔断两面不穿孔，手机隔壁可顺畅读卡 |
| **正面鸟类 SVG 工艺** | 凸起 `+0.6 mm` (`Z=2.5~3.1`) | 凹刻 `-0.6 mm` (`Z=3.0→2.4`) | 线宽统一约 `1.02 mm`，适配标准 `0.4 mm` 喷嘴 |
| **成品总高** | `3.1 mm` | `3.0 mm` | 扁圆柱币状比例 |

### 2. 极简曲线全贯穿中空支架（`stand_cone/nfc_stand_cone.stl`）
* **贯穿中空环壁**：无底封、无顶封，仅外围一圈光滑曲面薄壁（水平壁厚 `1.55 mm`），单只体积仅 **`1,419.9 mm³`**（约 **`1.76 g` PLA**）。
* **底部接触面**：窄环圈 **`Ø 15.0 mm`**（内孔 `Ø 11.9 mm`，底部边缘 `0.15 mm` 微倒角），优雅轻盈。
* **优雅贝塞尔凹曲线**：从窄环底向上先挺拔收腰再光滑外展至 `Ø 26.15 mm`（曲线高 `16.0 mm`，最大斜率角度严格控制在 `45.0°`，零支撑打印）。
* **无外凸台卡合顶部**：取消了外围承托台阶，曲线顶部直接转为 `1.1 mm` 高的直插环（外径 **`Ø 26.15 mm`**，含 `0.22 mm` 引导倒角，总高 `17.1 mm`），整体插进盖子背面的 `Ø 26.4 mm × 1.3 mm` 凹槽内侧卡住；盖内留给超薄 NFC 贴纸 `0.2 mm` 顶隙，外圈悬空呈现精致的伞盖感。
* **默认倒扣打印朝向**：导出的 `nfc_stand_cone.stl` 与 `all_9_stand_cones_plate.3mf` 已预先翻转 180°——将**宽大的 `Ø 26.15 mm` 圆环置于 `Z=0` 热床面**、窄口朝上，拖入 Bambu Studio 无需手动旋转即可直接零支撑稳固打印！

## 二、 切片与打印设置建议

1. **曲线支架打印**：
   * 摆放方向：**无需调整（文件已预置为宽口 `Ø 26.15 mm` 朝下贴热床、窄口朝上的倒扣方向）**，热床接触面积大、抓地极其稳固。
   * 支撑：**关闭**（最大曲面角度 45.0°，且为贯穿中空结构，无需任何支撑或桥接）。
   * 壁线/填充：建议设置 3～4 层墙，此时 `1.55 mm` 环壁几乎全由实心圈走线完成，单只耗材仅约 `1.76 g`。
2. **盖子双色与后处理**：
   * **凸起版**：底面朝下正放印刷，若需双色图案（例如白底黑鸟），在切片软件中 **`Z = 2.5 mm` 层高处添加换料暂停（Pause / Change Filament）** 即可获得锐利双色盖面。
   * **凹刻版**：底面朝下正放印刷，打印完成后可用丙烯颜料/填缝漆涂抹进凹槽再擦净表面，或者注入透明/有色滴胶封平。
3. **配合松紧微调**：
   * 不同打印机的耗材收缩率不同。建议**先各打印 1 个支架和 1 个盖子实测手感**：
     * 如果支架卡环塞进盖子时太紧，将 `3d_hardware/scripts/generate_stand_cone.py` 中的 `R_TOP` 从 `13.075`（Ø26.15）略微调小至 `13.00`（Ø26.0）；
     * 如果太松容易滑脱，可调大至 `13.125`（Ø26.25），或者用少量瞬干胶粘死固定。

## 三、 备选平底托盘方案（`legacy_bases/`）

若部分展示场合不想用 15mm 高的倒圆锥支架而希望盖子直接贴桌平放，可使用备选方案：
* `nfc_base_tray.stl`：外包式茶托底盘（外径 `Ø 34.2 mm`，内兜 `Ø 31.3 mm × 1.5 mm`），直接把整个盖子兜进去防掉芯片。
* `nfc_base_flush.stl`：等径齐平底盖（外径 `Ø 31.0 mm`，中间带 `Ø 26.0 × 0.4 mm` 定位凸台）。
* `nfc_base_plug.stl`：超薄塞片（`Ø 26.0 × 0.8 mm`），配合薄贴纸直接塞入盖背面凹槽实现零增厚封底。
